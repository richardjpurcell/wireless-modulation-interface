# WMI-CORE r2.7a — engineering draft

Sources: https://learn.adafruit.com/adafruit-esp32-s3-feather/pinouts ; https://www.adafruit.com/product/5323 ; https://learn.adafruit.com/adafruit-mcp4728-i2c-quad-dac/pinouts ; https://www.adafruit.com/product/4470 .

U3 and U4 are board-level functional symbols, not full physical pinouts. Pin IDs are silkscreen names; duplicated power pads and unused onboard connectors are omitted. J1 is a non-BOM logical boundary model, not a selected connector. It will be replaced by actual harness and hierarchical interfaces. The CSV includes J1 logical terminals; the existing checker may omit J1 if KiCad excludes it from netlist, in which case retain the raw export and review before altering checker. Local SYS_5V is not actually connected to WMI-PWR. PWR_FLAG is a conditional source annotation copied from the verified power sheet. No construction or USB servicing release. GPIO mapping to firmware constants, actual header positions, module supply budget, startup output isolation, reset topology and harness are outstanding. Use one VCC and one GND connection on DAC; do not connect an independent supply to the second VCC. LDAC tied low for immediate update; verify actual breakout revision and library update behavior. RDY and reserved outputs/expansion are not used externally yet. DAC_C/D are represented at logical boundary only. Firmware must write all four outputs to zero and verify successful transactions before READY; no repeated EEPROM writes. Use 100 kHz initial I2C. D13 onboard LED may blink at boot; not a safety indicator. USB pin external feed is provisional; never attach USB with the system harness connected. No battery or external source on BAT.
